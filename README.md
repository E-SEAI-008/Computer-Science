# Computer Science

Course material for the Computer Science module — covering everything from how computers work to Python programming and algorithms.

## What's in this repo

Live code written during lectures and exercise corrections, organized by module (if code is available):

- `01` — Computer Science Fundamentals (hardware, binary, networking, terminal)
- `02` — Python Basics (syntax, variables, collections)
- `03` — Python Fundamentals (control structures, functions, classes)
- `04` — Linear Data Structures I (Big O, arrays, basic sorting)
- `05` — Linear Data Structures II (advanced sorting, searching)
- `06` — Linear Data Structures III (stacks, queues)
- `07` — Non-Linear Data Structures I (hash tables, trees, BSTs)
- `08` — Non-Linear Data Structures II (graphs, shortest paths)
- `09` — Non-Linear Data Structures III
- `10` — SQL & Flask
- `11` — PCEP I
- `12` — PCEP II

## How to use this

Each module folder contains code from that week's lectures and corrections for the exercises. Check back after each session — new files will be added as we go.

## Running the Python files

```bash
python filename.py
```
